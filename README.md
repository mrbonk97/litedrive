# LiteDrive

> **최소한의 보안으로, 최대한의 속도를.**  
> 파일만을 위한 가장 단순한 공유 플랫폼.

---

## 개요

**LiteDrive**는 복잡한 절차 없이 빠르고 간결한 파일 공유를 목표로 한  
가벼운 클라우드 파일 전송 플랫폼입니다. 로그인부터 업로드, 다운로드, 공유 기능을 지원합니다.

---

## 보안 철학

- **탈퇴 시 모든 데이터는 즉시 파기되며, 복구가 불가능합니다.**
- **2FA(이중 인증) 등 부가 기능 없이**, 오직 파일에만 집중한 설계.
- 개인 정보를 최소화하여 불필요한 데이터 저장을 방지합니다.

---

## 핵심 기능

| 기능                | 설명                                              |
| ------------------- | ------------------------------------------------- |
| **2단계 파일 공유** | 업로드 → 링크 생성 → 다운로드. 단순하고 빠른 흐름 |
| **폴더 관리**       | 파일을 폴더 단위로 정리 및 공유                   |
| **즉시 삭제**       | 파일 및 계정 삭제 시 모든 데이터 즉시 파기        |
| **심플 UI**         | 불필요한 기능 없이 직관적인 인터페이스 제공       |

---

## 기술 스택

| 구분         | 사용 기술                                        |
